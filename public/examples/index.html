Example VIN Reports with Recall Data

Each link below opens a full, live mcp.vin report: specifications, recall campaigns, complaints, safety ratings and fuel economy from NHTSA and EPA data. Add any of these VINs to https://mcp.vin/api/vin/ to get the same report as JSON.

Reports with VIN-specific recall status

For these makes, mcp.vin also asks the manufacturer’s own recall lookup about the individual vehicle. That answer is separate from the list of campaigns for the model year, and it can change as repairs are made.

Reports with model-year recall campaigns

Every report lists the NHTSA recall campaigns for the make, model and year. A campaign on this list does not mean the individual vehicle is affected or unrepaired; check with the manufacturer or NHTSA.gov/recalls.

VehicleVINWhat the report shows
2003 Honda Accord EX-V61HGCM82633A004352A long recall and complaint history: useful for seeing how a large record is summarised
2024 Honda CR-V Sport-L5J6RS6H82RL008945A recent model with crash-test ratings and a short recall list
2015 Kia Optima5XXGR4A60FG353263Recall campaigns plus a five-star overall safety rating
2021 Hyundai KonaKM8K53AG0MU098173An electric model: recall campaign and safety ratings

Try one from the command line

curl https://mcp.vin/api/vin/1FTEX1EP4FFD06976

No API key or account is needed. See the API guide for every endpoint, or the recall guide for what recall records mean.
