Sources and independence

mcp.vin is an independent free service, not affiliated with or endorsed by NHTSA, EPA, the U.S. Department of Energy, Transport Canada, the Federal Reserve or any vehicle manufacturer. It shows what these public sources publish; it does not ask a manufacturer about any VIN.

  • NHTSA (U.S. National Highway Traffic Safety Administration), nhtsa.gov: VIN decoding (vPIC), recalls, complaints, investigations, crash ratings, test reports and photos, parts content (AALA), theft rates.
  • EPA and the U.S. Department of Energy, fueleconomy.gov and epa.gov: fuel economy, emissions, EPA test cars.
  • Transport Canada, tc.canada.ca (Canadian Vehicle Specifications, through NHTSA vPIC): model dimensions. Contains information licensed under the Open Government Licence – Canada.
  • Federal Reserve Board, federalreserve.gov (G.19 Consumer Credit): new-car loan rate benchmark.

Recall repairs for one VIN: mcp.vin links to the manufacturer’s own recall page and to NHTSA’s; it does not check them.

Frequently Asked Questions
What is a VIN and what does it stand for?

A VIN (Vehicle Identification Number) is a unique 17-character code assigned to every vehicle manufactured since 1981. It's stamped on the dashboard, the driver-side door jamb, and the engine block. Each character encodes specific information: the manufacturer, the country of origin, the vehicle type, engine specs, model year, assembly plant, and a serial number. No two vehicles in operation share the same VIN.

Where do I find the VIN on my car?

The easiest place to find it is on the driver-side dashboard — look through the windshield at the base where the dash meets the glass. You'll also find it on the driver-side door jamb sticker (the same one with the tire pressure info), on your vehicle registration card, and on your insurance card. Some cars also have the VIN stamped on the engine block or frame rail.

Is mcp.vin really free? What's the catch?

Yes, it's genuinely free — no signup, no API key, no hidden charges. mcp.vin pulls data from public government databases (NHTSA and EPA) that are already funded by taxpayers. There are no paid tiers or premium features. The REST API and MCP server are also free to use. The project is open source on GitHub.

What data does a VIN decode include?

A full VIN decode at mcp.vin returns the make, model, model year, body class, engine displacement, number of cylinders, fuel type, drive type, transmission, plant city and country, vehicle type, GVWR class, and safety equipment. It also includes NHTSA safety ratings, model-year recall campaigns, consumer complaints, EPA fuel economy data, and vehicle photos when available.

Does it work for vehicles outside the United States?

The NHTSA database primarily covers vehicles sold in the US market. However, many international manufacturers register their VIN patterns with the NHTSA, so vehicles from Japan, Germany, South Korea, and other major auto-producing countries often decode correctly even if they weren't sold in the US. The WMI (World Manufacturer Identifier) portion of the VIN is standardized globally by the ISO.

What's the difference between a free VIN check and a paid vehicle history report?

A VIN decoder can identify vehicle specifications and related model-year recall campaigns. Whether one car’s recall repairs are done is known only to the manufacturer and NHTSA: mcp.vin does not check it, and links to their VIN recall pages. An unknown result does not mean there are no open recalls. A vehicle history report may include reported accidents, title events, odometer readings, ownership and service records. Coverage varies; consider an independent inspection as well.

DEVELOPER TOOLS

Connect your tools

REST and MCP expose the research tools. The client and CLI below are included in this source build; they are not yet published to npm.

Connect via MCP

Use this server as an MCP tool in Claude Code, Claude Desktop, or any MCP-compatible client. Public tools need no API key. Account tools use the client’s OAuth connection.

Claude Desktop / Remote HTTP

Nothing to install, no API key and no account. Use the remote MCP endpoint:

https://mcp.vin/mcp

Or in config:

{
  "mcpServers": {
    "vin-mcp": {
      "url": "https://mcp.vin/mcp"
    }
  }
}

Claude Code stdio

Clone the source repository and run locally. Add to your project’s .mcp.json:

{
  "mcpServers": {
    "vin-mcp": {
      "command": "node",
      "args": ["/path/to/vin-mcp/server.mjs"]
    }
  }
}

Vehicle reports · 4 tools

decode_vin (vin, transmission)

Decode a VIN and return a vehicle report: specs, recalls (with manufacturer build-date ranges), a complaint summary with the most recent complaints, safety ratings, fuel economy, EPA test-vehicle data, parts content and origin (MY2020+), historical production and theft (MY1998-2012), and photos of NHTSA's own test vehicle (photos: null when none of the same make, model, body style and generation was tested; never the decoded vehicle, no stock photos; each item names its test car, NHTSA test and phase, before or after the crash test). decode_checks checks the official decode field by field (drive, engine, electrification, transmission, speeds, seats, GVWR) against mcp.vin's reviewed fixes of NHTSA's vPIC rules, NHTSA test vehicles with the same VIN pattern and EPA's configurations: confirmed, corrected, doubtful or filled, with vPIC's original value kept. recalls are NHTSA's campaigns for the make, model and year, not this vehicle's repair status. mcp.vin does not check a VIN's recall repairs with the manufacturer or NHTSA: recall_status gives links to check them (manufacturer_lookup_url, VIN filled in where vin_prefilled is true; nhtsa_lookup_url), with open_count and completed_count null (unknown, never zero). NHTSA's complaint list for a common model can take 15 s or more: complaints.pending true is unknown, not zero; call decode_vin again in a minute (cached once it arrives).

validate_vin (vin)

Quickly validate a VIN without calling any external APIs.

lookup_recalls (vin, make, model, year)

Look up recalls for a vehicle. Provide either a VIN or make/model/year.

batch_decode (vins)

Decode multiple VINs at once (up to 50).

Research and analysis · 13 tools

explore_capabilities

Discover supported features and explicit coverage gaps.

vin_recall_status (vin)

Where to check one VIN's recall repairs. mcp.vin does not ask the manufacturer or NHTSA about a VIN: this returns links, manufacturer_lookup_url (the maker's own recall page; the VIN is filled in where vin_prefilled is true, else enter it there) and nhtsa_lookup_url (NHTSA's VIN recall page, all makes), with open_count and completed_count null: unknown, never zero. Makes without a known maker page get NHTSA's link only. For the recall campaigns of the model year use lookup_recalls or decode_vin.

vehicle_catalog (level, year, make, model)

Browse EPA year, make, model and configuration menus. Not sale listings.

epa_vehicle (id)

Get an explicitly selected EPA test configuration; not an exact VIN match.

vehicle_emissions (id)

Get EPA emissions for an explicit EPA vehicle ID.

fuel_price_assumptions

EPA fuel-price assumptions, not local station prices.

owner_reported_mpg (id)

Voluntary owner-reported MPG for an EPA configuration, including sample size and limitations.

defect_investigations (year, make, model, offset, limit)

Search NHTSA model-year defect investigations with retained source variants and snapshot dates.

auto_loan_benchmarks

Dated Federal Reserve new-car loan benchmark snapshot, not personalized or live loan rates.

vehicle_dimensions (year, make, model)

Canadian model-variant dimensions in cm and kg. Not VIN-specific.

manufacturer_communications (year, make, model, offset, limit)

Search indexed NHTSA communications, with source coverage. Bulletins are not recalls.

compare_vehicles (vins)

Compare 2–4 distinct VINs without treating missing data as zero or counts as safety rankings.

ownership_scenario (price, apr, months, down_payment, tax_amount, fees, ownership)

Calculate fixed-rate payments and optional ownership costs from explicit assumptions; not lender or tax quotes.
